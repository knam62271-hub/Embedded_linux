# TASK 2 – COUNTER DEVICE TEST

**1. Nạp driver**
```bash
insmod /lib/modules/5.15.0/counter_driver.ko
lsmod
```
Driver được nạp thành công. Major `10`, minor `125`.

**2. Kiểm tra READ**
```bash
cat /dev/counter
```
Kết quả ba lần đọc:
```text
0
1
2
```

**3. Kiểm tra WRITE**
```bash
echo 100 > /dev/counter
cat /dev/counter
```
Kết quả: `100`.

**4. Kiểm tra RESET**
```bash
echo 0 > /dev/counter
cat /proc/counter_info
```
Counter trở về `0`.

**5. Kiểm tra dữ liệu không hợp lệ**
```bash
echo -5 > /dev/counter
echo abc > /dev/counter
```
Cả hai đều trả về `Invalid argument`.

**6. Gỡ driver**
```bash
rm /dev/counter
rmmod counter_driver
lsmod
```
Driver được gỡ thành công.

**Kết luận:** Các chức năng READ, WRITE, RESET, kiểm tra dữ liệu không hợp lệ và `/proc/counter_info` đã được kiểm thử thành công trên QEMU.
